测试质量与局限

HTTP 采样

下载目标为 Cloudflare HTTP 节点，不保证物理国家；空闲与负载延迟使用同域 Worker /api/ping，二者与下载服务不一定走完全相同的服务路径，且不是 ICMP Ping。负载探测与下载并发发起，但并不等同于精密 TCP 队列延迟测量。下载采样有间歇，预算可能导致提前结束；未测到的项目保持空白。

高级设置与流量预算 （默认已设置好）

基准测速默认约 60 秒、预算 80 MB；跨境网站、应用探测、分片模拟会产生额外流量。浏览器在后台或锁屏后不能保证连续测试。
